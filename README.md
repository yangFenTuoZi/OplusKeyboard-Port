# OplusKeyboard-Port

运行 `tools/prepare-apk.sh` 前，将 Maven Central 上的 `org.lsposed.hiddenapibypass:hiddenapibypass:6.2` AAR 放在 `input/hiddenapibypass-6.2.aar`。也可以用 `OPLUS_IME_HIDDEN_API_AAR` 指定已有文件。键盘用这个库查找背景模糊所需的方法。[Maven Central](https://central.sonatype.com/artifact/org.lsposed.hiddenapibypass/hiddenapibypass/6.2)
